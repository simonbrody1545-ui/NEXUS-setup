NEXUS PUBLIC WEBSITE
====================

This is a separate, static public website. It does not contain or host your
private local NEXUS dashboard.

PREVIEW ON YOUR PC
1. Open this NEXUS-PUBLIC folder in VS Code.
2. Install/use the Live Server extension if needed.
3. Right-click index.html and choose "Open with Live Server".

ADD YOUR WINDOWS INSTALLER
1. Put your installer inside the downloads folder.
2. Rename the installer to exactly: NEXUS-Setup.exe
3. The download page already links to downloads/NEXUS-Setup.exe.

IMPORTANT SECURITY
- Do not put API keys, passwords, private certificates, config secrets,
  private logs, or your private dashboard files in this public folder.
- The public website is static. The private dashboard remains on your PC.
- Before publishing, make sure you are allowed to distribute the installer
  and check it contains no personal secrets.
- If you use GitHub Pages or Cloudflare Pages, publish only this folder.
- Free static hosting providers have file-size and usage limits. If the EXE
  is too large, use a separate file host that permits public downloads.

PUBLISH FOR FREE
Cloudflare Pages or GitHub Pages can host the static site. Upload/publish
the contents of this NEXUS-PUBLIC folder. The free hosting provider gives
you a public web address; you do not need to buy a domain.
